# 瑞士字体

核心：非对称网格与大标题。

- 不变：一个清晰主视觉，主题关系具体，标题可辨。
- 可变：主体、尺度、剪裁、字图互动与兼容配色。
- 兼容配色：ink-ivory, charcoal-red, cobalt-terracotta。
- 构图骨架：type-field, ruled-grid。
- 默认字体：swiss。
- 失败：堆砌装饰、内容无关的符号、主次不清或标题损坏。
- 飞书：重要标题与主体识别锚点集中在中央安全区，外围仅放可裁元素。

## 风格辨识与质量门

固定：非对称网格、清晰的字重层级和几何秩序，少量实色。变化：网格比例、字的位置、几何重心。失败：机械均分的卡片与无意义的数据。
