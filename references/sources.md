# 来源

本 skill 面向 AI、技术、产品、工作方法与其他主题的文章系列。横屏排版、中英衬线字体与使用场景适配是本项目的设计选择。

- 研究：[mono-color-skill](https://github.com/yanliudesign/mono-color-skill)，2026-10-29所见main树SHA c8ff70597ddedcd65f21a0b528f6a70c35690b0a。借鉴两墨职责、主动留白、机械复制、图字关系与原创性规则。未打包其第三方参考图或作者示例。
- [飞书封面要求](https://www.feishu.cn/hc/zh-CN/articles/990851076781-recommendations-for-covers-in-docs)：2000×400、中央580×240，查询2026-10-29。点名平台或发布前需要复核时再读官方源。
- [Adobe Source Han Serif](https://github.com/adobe-fonts/source-han-serif)，随附2.003R的SC SemiBold原版OTF。
- [Bodoni Moda](https://github.com/google/fonts/tree/main/ofl/bodonimoda)，normal/italic variable TTF。
- [Cormorant Garamond](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond)，normal/italic variable TTF。
- [IBM Plex Mono](https://github.com/google/fonts/tree/main/ofl/ibmplexmono)，Regular TTF。

原版权与完整OFL许可在assets/fonts/；实际下载URL、字节数、SHA-256在manifest.json。不修改字体，不打包系统商业字体。模型字形外观接近与实际加载字体文件须明确区分。
